That page is not here. Try the [documentation home](/starlight-llm-actions/).

Starlight renders a 404 page whether or not the collection holds a `404` entry.
Shipping a real one means the entry *is* in the collection, which is what makes
this page a test fixture: the site indexes must leave it out, and no page may
advertise it as its Markdown alternate.
