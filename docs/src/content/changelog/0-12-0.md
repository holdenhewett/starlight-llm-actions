description: A subset's paths now override exclude.
date: 2026-07-14
area: llms.txt
changeType: feature
---

A `subsets` entry whose `paths` name an excluded page now carries that page,
so a section too large for `llms-full.txt` can still ship as its own bundle.

Nothing about the per-page Markdown routes changed.
